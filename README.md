# uminaibi-resin.jp 運用手順書

## しくみ
- このサーバー（R-ENTRY と同じ VPS）で**作る・直すだけ**。公開はしない。
- 公開先は uminaibi-resin.jp の今のサーバー（157.7.189.64・ムームードメインで向き先を設定済み）。
- 送り方は FTP。`bin/deploy.sh` が `site/` の中身を、サーバーの公開フォルダへ送る。

## 初回の準備
1. `cp deploy.env.example deploy.env && chmod 600 deploy.env`
2. `deploy.env` に FTP のホスト・ユーザー名・パスワード・公開フォルダを書く
3. `bin/deploy.sh`（確認のみ）で、つながるか・何が送られるかを見る

## 直して公開する
| 手順 | やり方 |
|---|---|
| 1. 直す | `site/` のファイルを直す（ビルド不要） |
| 2. 確かめる | `bin/deploy.sh` … 送られるファイルの一覧が出る（まだ送らない） |
| 3. 送る | `bin/deploy.sh --go` |
| 4. 記録 | `git add -A && git commit -m "内容" && git push origin main` |

★サーバーにだけあるファイル（前の WordPress の名残など）は消さない作りにしてある。

## フォルダ
- `site/` … 公開するファイル
- `bin/deploy.sh` … FTP で送るスクリプト
- `deploy.env.example` … 接続情報のひな形（本物の `deploy.env` は git に入れない）
- `docs/` … 課題・決定ログ

## オンラインショップ（Stripe の「支払いリンク」）（2026-10-27）
しくみ：ショップのページ（`site/shop.html`）の「購入手続きへ」ボタンから、Stripe の決済ページへ移ります。
カード番号・お届け先の入力、領収書のメールは Stripe がします。このサイトにプログラムやパスワードは置きません。

### 準備（1回だけ・Stripe の管理画面で）
1. Stripe のアカウントを作り、本人確認・お店の情報・振込先の口座を登録する。
2. 「設定 → 公開情報」で、特定商取引法の表記の URL に https://uminaibi-resin.jp/tokushoho.html を書く。
3. 「設定 → カスタマーへのメール」で「支払い成功時」の領収書メールをオンにする。
4. 「配送料」を作る（送料を決めたとおりに）。

### 商品を1つ売り出す
1. Stripe で「商品」を作る（名前・税込の価格・写真）。
2. その商品の「支払いリンク」を作る。設定：
   - 配送先住所を集める（国は日本）、上で作った配送料を付ける
   - 一点ものは「支払い回数を制限する」を 1 回に
   - 「支払い後」→「自分の Web サイトにリダイレクト」→ https://uminaibi-resin.jp/shop-thanks.html
   - 「カスタムテキスト（支払いボタンの上）」に「お支払い後のキャンセル・お客様都合の返品はできません。発送は○営業日以内。くわしくは特定商取引法に基づく表記をご覧ください」
     （★法律で、最後の確認画面に「いつ払うか・いつ届くか・キャンセルの条件」を出すことになっているため）
3. `site/shop.html` の見本の `<article>` をコピーして書き換え、ボタンの href に支払いリンク（https://buy.stripe.com/...）を貼る。
4. 売り切れたら、ボタンを「売り切れ」に替える（ファイルの中に書き方あり）。

★【要確認】が残っているページがあると、`bin/deploy.sh --go` は送りません（仮の文が公開されないように）。
