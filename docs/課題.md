# 課題（2026-10-26 時点）

## すぐ直したほうがよいもの
1. **お問い合わせ・予約フォームが送信されていない**。contact.html の送信ボタンは「送信しました」と表示するだけで、内容はどこにも届かない（擬似送信）。お客様の予約・問い合わせが消えている可能性がある。→ メール送信またはデータベース保存の仕組みを付ける。
2. **リンク先が仮のまま**：Instagram（https://www.instagram.com/）、LINE（https://line.me/）、Google マップ（https://maps.google.com）が、店のページではなくトップページを指している。
3. **ギャラリー画像が仮**：`images/gallery/xxx.jpg` を参照しているが画像が無い。
4. **Tailwind を CDN（cdn.tailwindcss.com）で読み込んでいる**：開発用で、本番向けではない（表示が遅い・警告が出る）。ビルドして CSS ファイルにする。

## 確認すること
- 体験教室の料金・所要時間・予約方法の表示（特定商取引法・景品表示法）
- 特定商取引法に基づく表記・プライバシーポリシーのページが無い（オンライン予約・決済をするなら必要）
- 公開サーバー（157.7.189.64）の robots.txt に WordPress の名残（/wp-admin/・wp-sitemap.xml）がある。site/robots.txt を送ると上書きされる
